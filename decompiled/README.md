Декомпилированная структура невозможна для большинства файлов.

В этом репозитории содержится только один исходный Python файл __init__.py и 26 скомпилированных модулей (.so).
Модули .so представляют собой ELF-бинарные файлы ARM aarch64, stripped, и не могут быть восстановлены в читаемый Python-код.

Тем не менее, для каждого файла .so извлечена служебная информация:
- ELF-заголовок
- экспортированные динамические символы
- вхождения строк с Python-терминами

Структура:
- sdk/__init__.py: оригинальный пустой файл пакета
- compiled_modules/: описания каждого .so файла с извлеченными данными
